# Delivery outcomes

## Responsive landing page and navigation
- Build a responsive commercial leasing and brand directory landing page for Bogo City Centrum in Taytayan, Bogo City, Cebu.
- Include section links for Home, Brand Logos, 2D Satellite Map, Leasing Spaces, and Location, plus the Inquire To Lease and Admin Brand Studio actions.
- Use the confirmed visual system: #0A4D8C coastal blue, #4CAF50/#65B32E leaf green, #EFF6FF and #F0FDF4 soft tints, white elevated cards, 15px radii, 24px padding, geometric sans typography, and script accent styling.
- Use the supplied Centrum building photo in the main hero with a layered blue/green gradient treatment, stronger contrast, and a premium editorial presentation.

## Hero and brand directory
- Include the split editorial hero with location badge, headline, supporting copy, leasing/map CTAs, architectural visual, floating site descriptor, and featured brand logo strip.
- Include a filtered directory grid for 7-Eleven, Rose Pharmacy, MR.DIY, LandBank, Palawan Pawnshop, Sun Savings, Nuat Thai, and available leasing slots.
- Each directory card must expose brand/category, building/unit, floor area, occupancy state, and an inquiry action.

## Benefits, leasing flow, and footer
- Include the dark blue benefits banner with visibility, central parking, brand mix, national/local business points, and a site-visit CTA.
- Include the four-step leasing process, four-column metrics bar, leasing CTA, and high-contrast footer with address, contact details, tagline, and admin trigger.

## Interactive map and Admin Brand Studio
- Include a 2D architectural map with Building A and Building B facing central parking, clickable lots, ground/second floor switching, legend, parking bays, walkways, greenery, and entry/exit details.
- Include Admin Brand Studio mode with lot selection, preset brands and availability states, editable brand name, logo badge, category, occupancy status, floor area, and Save Changes.
- Saving an admin edit must update the selected lot, map badge/state, and directory card data immediately.
